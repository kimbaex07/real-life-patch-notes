One line from the comedy changelog: a patch note for the bug where the
brain replays the same embarrassing memory from 2014 every night at
3 a.m. instead of sleeping. An entry for the make.fun bounty
[Real-Life Patch Notes: The Comedy Changelog](https://make.fun/bounty/u-0xb3e689-real-life-patch-notes-the-comedy-changelog-c5844c1d).

Why this bug: it is the one every human has shipped with since forever —
no update ever fixed it, no workaround exists, and the repro steps are
just "go to bed". The note reads like a real release note because the
bug reads like a real defect: wrong output, wrong time, every night.

## Run it

```sh
python3 main.py
```

This writes the one-line patch note to `entry.txt` (and to
`/output/entry.txt` when the grading sandbox provides `/output`).
